# 应用截图

此目录存放 README.md 中展示的应用截图。

## 需要的图片

| 文件名 | 内容 | 建议尺寸 |
|-------|------|---------|
| `menubar.png` | 菜单栏弹出界面 | 原始尺寸 |
| `menubar-dark.png` | 菜单栏（深色模式） | 原始尺寸 |
| `break-blur.png` | 休息界面-毛玻璃效果 | 1280x800 或更高 |
| `break-glass.png` | 休息界面-液态玻璃 | 1280x800 或更高 |
| `settings.png` | 设置界面 | 原始尺寸 |
| `statistics.png` | 统计界面 | 原始尺寸 |

## 截图方法

使用 macOS 自带截图工具：

- `Cmd + Shift + 4 + Space`：截取带阴影的窗口
- `Cmd + Shift + 5`：录制屏幕

## 图片优化

建议使用 [TinyPNG](https://tinypng.com) 压缩图片，减小仓库体积。
