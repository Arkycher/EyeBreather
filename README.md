# EyeBreather

一款优雅的 macOS 护眼提醒应用，基于 20-20-20 法则帮助你保护视力。

## 功能特性

### 智能休息提醒
- **20-20-20 法则**：每 20 分钟工作后，提醒你休息 20 秒，看向 20 英尺（约 6 米）外的地方
- **可自定义时长**：灵活设置工作和休息时间
- **休息预警**：休息前 60 秒提前通知

### 三种提醒模式
- **温和模式**：可随时跳过或延迟休息
- **强制模式**：必须完成休息才能继续工作
- **渐进模式**：连续跳过多次后自动切换为强制模式

### 智能检测
- **活动检测**：检测用户是否在使用电脑，空闲时自动暂停计时
- **会议检测**：检测摄像头/麦克风使用状态，会议中自动暂停
- **专注应用**：指定应用（如 Zoom、腾讯会议）运行时自动暂停

### 精美休息界面
- **毛玻璃效果**：现代感十足的模糊背景
- **液态玻璃**：macOS 26 原生 Glass Effect
- **桌面壁纸**：使用你的桌面壁纸作为背景
- **深色模式**：简约的纯黑背景
- **自定义图片**：使用你喜欢的图片

### 其他特性
- 菜单栏常驻，不占用 Dock
- 勿扰时段设置
- 开机自启动
- 休息统计数据
- 深色/浅色/跟随系统主题

## 系统要求

- macOS 14.0 (Sonoma) 或更高版本
- Apple Silicon 或 Intel 处理器

## 安装

### 方式一：下载安装包

1. 前往 [Releases](https://github.com/Arkycher/EyeBreather/releases) 页面
2. 下载最新版本的 `.dmg` 文件
3. 打开 DMG，将 EyeBreather 拖入 Applications 文件夹
4. 首次打开时，右键点击应用 → 打开 → 点击「打开」

### 方式二：从源码构建

```bash
# 克隆仓库
git clone https://github.com/Arkycher/EyeBreather.git
cd EyeBreather

# 使用构建脚本（需要先安装 create-dmg）
brew install create-dmg
./scripts/build.sh
```

构建产物位于 `dist/` 目录。

## 使用说明

1. 启动应用后，会在菜单栏显示眼睛图标
2. 点击图标可查看当前计时状态
3. 点击「设置」进入偏好设置
4. 根据个人习惯调整工作时长、休息时长和提醒模式

## 隐私说明

EyeBreather 完全离线运行，不会收集或上传任何用户数据。

- 活动检测仅用于判断是否暂停计时
- 摄像头/麦克风检测仅用于判断是否在会议中
- 所有设置数据仅存储在本地
